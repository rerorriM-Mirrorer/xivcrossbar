# Optional templates and presets

Author A. These files are starting points to copy or merge deliberately; the
addon does not auto-install them into your data folder.

| Example | Contents |
| --- | --- |
| CustomActions-template.xml | Existing 34-action template. See CUSTOM-COMMANDS.md for dependencies and import details. |
| presets/fenrir-20261016/ | Recovered Cioara All Jobs Default, adjusted Franklet/Lionstag copies, paired global catalog, original catalog reference and optional suggestions. See its README. |

The preset catalog and the generic template share action IDs. Choose the desired
starting catalog or merge deliberately through the editor; do not concatenate
both catalogs or import either twice. The recovered preset catalog includes
newer values from its accompanying bar and is distinct from the generic template.

These are personal development examples, not public RC3 defaults. They retain
explicit character destinations and historical commands/dependencies. They are
not a new export of the currently running PC and do not implement the proposed
L1 inventory/emote, NPC or Trust companion layouts.
