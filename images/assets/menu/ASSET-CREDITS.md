# Menu assets

L2/R2 vector adaptations inspired by Antoine Plu’s PlayStation Controller Icons.
Source: https://www.figma.com/community/file/968584708653901737/playstation-controller-icons
Author: https://www.figma.com/@antoineplu
Reference license: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/
Changes: reconstructed trigger silhouettes with negative-space lettering.

Rounded page-button background: A.

Golden cursor: six PNG frames extracted from the supplied 51.DAT texture anc/anc.
Original FFXI assets remain their respective owner’s work. Extraction provenance
is in cursor/provenance.json. 12 fps is a preview choice, not verified game timing.
