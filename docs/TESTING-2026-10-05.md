# Visibility and presentation test — 0.4.0-a.20261005.1

XIVCrossbar development belongs in rerorriM-Mirrorer/xivcrossbar. NPCmirror,
SlowEnter and AddonToggle remain independent. This source batch does not alter
personal hotbar XML, server detection or controller scripts. A Fenrir-only
installation package and the forthcoming all-jobs bindings are separate work.
The historical snapshot builder preserves all profiles; it does not perform
that forthcoming Fenrir cleanup.

Use the complete matching Lua source, including theme.lua and ui_geometry.lua;
copying only xivcrossbar.lua is insufficient. Back up the current installation
before testing. Existing settings remain authoritative over new defaults.

1. Check `//xb ui status`. Try `//xb autohide on`, release triggers and confirm
   the configured delay. Try `//xb ui grace 10`, then restore `//xb ui grace 5`.
   Bare `//xb autohide` toggles the saved mode. Bare `//xb ui` toggles temporary
   visibility; `//xb ui auto` clears that override.
2. During a cutscene, explicit `//xb ui show` should reveal the bar; `auto`
   should hide it again. Confirm ordinary bindings still execute as before.
3. Try `//xb ui scale 0.75`, then `1`. Icons, aliases, cost/recast labels,
   indicators and outlines should scale together. A Goring Blade icon must
   remain bounded after repeated reveals. Try `//xb ui aliasoffset -5 -10`,
   then `0 0`; cost and recast text should stay in place.
4. Unlock, hover over the Drag tile and drag it. Look for the white layout
   outline, pink feedback and lock hint. Lock and reload to check persistence.
   Explicit Hide must remove the overlay and prevent invisible dragging.
5. Move the bar, open the binder and confirm the menu remains centered with
   its title, background, choices and footer together. Try `menuscale 0.75`
   and `menuscale 1` through the UI command. Test at your smaller resolution.
   The known action-type NEXT bug and missing review trigger-paging are still
   pending; this batch changes menu geometry, not those navigation workflows.
6. Confirm self-only action selection no longer prints the STPC diagnostic.
   Compare reveal smoothness with the old build. Unchanged texture paths are
   reused, but the live hitch has not been measured or established as fixed.

Offline validation: the standalone LuaJIT regression suite passes, including
renderer/binder geometry at 640x480, 1280x720, 1366x768, 1600x900 and 3840x2160.
All 43 Lua files pass syntax checks under Lua 5.1 semantics, with the inherited
Windower string-literal extension normalized only in a temporary check copy.
Native Windower drawing and live controller behavior still require game tests.
