# Batch 1 — Menu repair

Build `0.4.0-a.20261005.9`, based on controller branch `bec1928`.

Main-menu confirmation previously submitted the selection twice. The first
submission cleared it, producing the logged nil access on the second. This
batch captures the navigation position first and reuses the returned option.

Execute Command, Superwarp and credit-panel avatars now use paths rooted at
`images/`. Missing menu icons get a fallback, one warning per path and console
details. Execute Command remains usable without a generated icon catalogue.

Selector pages release old native text/image objects instead of retaining
every visited page. Icon-folder diagnostics identify directory listing and
each texture's load start/end, helping distinguish a Lua error from a native
renderer failure. The `extra` crash is not claimed fixed by these checks.

Validation: reproduced the reported line-813 failure before the change. The
new entry/resource regression, the existing suite and Lua 5.1 syntax checks
pass after it. Windows controller behavior and native texture loading still
need the player's live test.

Live checks: open all three utility/credits screens; create Bow through the
menu; enter `input /bow <t>`; save/bind/use/reload; visit `extra` and retain the
last `[XIVCrossbar icons]` lines if it fails again.

The prepared L3/shoulder update is inherited. Keep local controller Joy
mappings; use the clean global settings supplied with each test package.
