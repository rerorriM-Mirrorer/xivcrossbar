replacing its folder. Keep the currently running AHK arrangement for this first

## Checks in the repository

Run from the repository root with Lua 5.1 or LuaJIT:

```text
luajit tests/run.lua
```

These regressions run the actual selector, binder, player, rendering lookups and
main event handlers with external Windower services stubbed. They cover empty
icon folders, paged editing, loaded binding refresh, layer precedence, isolated
Shared, Quick Switch returns, drag capture/persistence, sparse 3/4/6-bar pages,
release grace and cutscene/manual visibility. A fresh checkout does not need
generated resource caches to run them.

Static compilation checks use `python3 tools/check_syntax.py --lua luajit`.
That accounts for the inherited Windower literal-method syntax in a temporary
copy; runtime files stay unchanged. See the validation report for scope.
Offline tests do not establish actual mouse-camera behavior, controller input,
multi-window switching, warp success, or CPU/FPS improvements.
